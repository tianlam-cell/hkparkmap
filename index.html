關於路線／交通資料的說明（第三方路線引擎、預測交通、事故配對方式）
路線由第三方開放路線引擎 OSRM（based on OpenStreetMap 路網）計算， 並非香港政府官方數據，僅供路線參考，實際駕駛請以現場交通標誌及政府公佈資訊為準。網站會嘗試取得多條路線（包括額外請求一條避開快速公路的走法），但 OSRM 的替代路線演算法門檻較高，並非每次都能像 Google 地圖般保證有多條可選，如只得一條路線，代表 OSRM 未能找到路況相近但走法明顯不同的替代路徑。

路線顏色（交通繁忙程度，見地圖右上角圖例）根據運輸署「交通數據分析系統」提供的預測平均車速換算，每 5 分鐘更新一次，屬預測性質，非逐秒實時路況；沿途紅燈攝影機、車速攝影機提醒基於官方座標資料計算。特別交通消息大部分政府記錄沒有提供座標，本網站只計算有座標的事故是否在沿途 50 米範圍內，沒有座標的事故不會計入（避免不準確的猜測），如顯示「沒有」，代表沿途暫時沒有已知座標的相關事故，並非保證完全沒有事故發生。

關於巴士／小巴路線資料的說明
路線、巴士站及到站時間來自運輸署／九巴／城巴的官方開放數據。地圖上的路線是按站序把各個巴士站以直線連接，並非實際行車路徑。到站時間點擊巴士站才會查詢，數據約每分鐘更新，只供參考。

按起點／終點搜尋：計算九巴／龍運、城巴和專線小巴的直達或轉乘一次方案（轉乘可跨營辦商）。城巴和專線小巴沒有「一次取得全部站點」的官方介面，所以網站讀取同一資料夾內的 transit-data.json，這個檔案由 GitHub Actions 每日從官方 API 彙整；如果找不到這個檔案時，會自動改用社區整合資料集 data.hkbus.app（HK Bus Crawling，非官方，每日整合官方開放數據，約 8MB，首次載入需時）；兩者都失敗才只計算九巴／龍運。時間是估算：步行按直線距離 ×1.25、每分鐘 80 米；乘車按站間直線距離 ×1.3、平均時速約 17 公里；每次上車另加 5 分鐘候車。官方沒有提供班次表，所以候車時間只是假設，並非實際班次。

未包括：新大嶼山巴士、港鐵巴士、紅色專線小巴及公共小巴（沒有公開的站點資料）。
