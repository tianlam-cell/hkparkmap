1. 直達路線置頂
「起點／終點」的乘車方案結果，現在永遠先列「直達」，再列「轉乘一次」，兩組各自按你選的「最短時間」或「最少步行」排序。以前兩種混在一起排，轉乘方案可能排在直達前面。

2. 選路線後列出站，點站看到站時間

「按路線號碼搜尋」：選了路線後，面板會列出該路線所有巴士站。
「起點／終點」：點選某個乘車方案後，面板會列出每一程從上車站到落車站的所有站，標示「上車」「落車」。
點任何一個站，該站下方會展開到站時間（最多三班），再點一次收起。地圖也會移到該站，手機上會避開被面板蓋住的位置。
專線小巴在整合資料集來源下的方案，到站時間查不到，會提示你改用「按路線號碼搜尋」。

3. 根據現在位置找最近的站

站列表下面有「📍 根據現在位置，找最近的站及到站時間」按鈕。按下去會定位，在列表中標出最近的一個站（綠色標記），顯示每個站距離你多遠，並自動展開那一站的到站時間。
「起點／終點」的方案有兩程時，每一程各找一個最近站。
如果最近的站超過 1.5 公里，會提示這條路線可能不經過你附近。
